# SurfTracker — оффлайн-инструменты разметки

## 1. Нарезка кадров
```bash
cd ~/Projects/SurfTracker
.venv/bin/python tools/extract_frames.py                  # каждый 15-й кадр + фильтры → Data/frames/labeled/
.venv/bin/python tools/extract_frames.py --every-sec 1.0  # шаг по времени (fps у видео разный: 30 и 60!)
.venv/bin/python tools/extract_frames.py --dry-run        # только посчитать, ничего не писать
```
- Дедуп: dHash (`--hash-dist 6`, 0 = выкл). Блюр: Laplacian variance (`--blur-thresh 40`, 0 = выкл).
- `Data/frames/labeled/frames_manifest.csv` — из какого видео/кадра каждая картинка. **Train/val сплит делать по видео**, иначе утечка.
- Внимание: `VID_20230710_150051.mp4` вертикальное (1080×1920).

## 2. Разметка — X-AnyLabeling (основной)
```bash
xanylabeling   # шорткат (~/.local/bin/xanylabeling), работает из любой папки; есть и в меню приложений
```
Вручную (то же самое):
```bash
cd ~/Projects/SurfTracker/tools/X-AnyLabeling
../../.venv-label/bin/python anylabeling/app.py
```
- Открыть папку `Data/frames/labeled/`, размечать bbox, класс `Windsurf`.
- AI-ассист оффлайн: SAM-веса лежат в `~/xanylabeling_data/models/` (MobileSAM, SAM2.1-tiny).
- **Наша модель v1 как автодетектор**: в панели Auto Labeling → выпадающий список моделей →
  `...Load Custom Model` → выбрать `models/xany_yolo11s_windsurf.yaml` (рядом лежит
  `v1_yolo11s_e99.onnx`, экспорт из `v1_yolo11s_e99.pt`, imgsz=1280, conf=0.30). Класс — `Windsurf`.
  «Прогнать по всем кадрам» — кнопка Run all images (Ctrl+M).
- **Статус проверки кадра**: `Ctrl+Alt+K` — пометить текущий кадр как Checked (галочка в списке
  файлов; хранится как `"checked": true` в JSON кадра). Импортированная предразметка статус
  не ставит — все кадры изначально Unchecked. Фильтр в поиске списка файлов: `checked::0` —
  только непроверенные, `checked::1` — только проверенные.
- Экспорт: Export → YOLO / COCO.
- Fallback: `.venv-label/bin/labelme Data/frames/labeled/ --labels Windsurf --nodata` (прямоугольники: Create Rectangle).

## 3. Предразметка моделью v1
Обучена (см. `docs/journal/ОБУЧЕНИЕ_v1.md`): `models/v1_yolo11s_e99.pt`, 1 класс `windsurf`.
```bash
.venv/bin/yolo predict model=models/v1_yolo11s_e99.pt source=Data/frames/yt1_unlabeled/ \
  save_txt save_conf conf=0.3 imgsz=1280
# → runs/detect/predict/labels/*.txt (YOLO-формат, импортируется в X-AnyLabeling: Upload → YOLO labels + classes.txt)
```
`classes.txt`: один ряд — `windsurf`. Старый Roboflow-датасет (учтён при обучении v1):
`Datasets/SurfTracker_v7`.

## 4. CVAT + auto-annotation (запущен)
Репо: `~/Install/cvat`, UI: http://localhost:8080. Запущен с serverless-компонентами (nuclio):
```bash
cd ~/Install/cvat
docker compose -f docker-compose.yml -f components/serverless/docker-compose.serverless.yml up -d   # старт
docker compose -f docker-compose.yml -f components/serverless/docker-compose.serverless.yml down    # стоп (без -v — данные целы)
```
- Auto-annotation: задеплоена функция **YOLOv11s Windsurf v1** (наша `models/v1_yolo11s_e99.pt`,
  класс `windsurf`, imgsz=1280, порог по умолчанию 0.3). В UI: Models → или магия-кнопка в задаче.
- Исходники функции: `~/Install/cvat/serverless/custom/yolov11s-windsurf/nuclio/`.
- Передеплой (образ уже собран, сборка оффлайн):
  `cd ~/Install/cvat/serverless && nuctl deploy --project-name cvat --path custom/yolov11s-windsurf/nuclio --file custom/yolov11s-windsurf/nuclio/function-run.yaml --platform local --env CVAT_FUNCTIONS_REDIS_HOST=cvat_redis_ondisk --env CVAT_FUNCTIONS_REDIS_PORT=6666 --platform-config '{"attributes": {"network": "cvat_cvat"}}'`
- ВАЖНО: при включённом VPN-клиенте с подменой DNS (fake-DNS) docker-сборки с выходом в сеть
  падают (fake-DNS отдаёт только IPv6-адреса, у контейнеров IPv6 нет). Пересборка образа с
  новыми весами — выключить VPN, либо собрать staging вручную с `--add-host` (см. function.yaml
  vs function-run.yaml).
