## Каким разметчиком пользоваться: X-AnyLabeling (рекомендую)

Причины: работает полностью оффлайн, AI-ассист (SAM по клику даёт рамку),
умеет импортировать предразметку YOLO, экспорт сразу в YOLO-формат.

### Запуск
```bash
cd ~/Projects/SurfTracker/tools/X-AnyLabeling
../../.venv-label/bin/python anylabeling/app.py
```

### Порядок работы
1. **File → Open Dir** → выбрать `~/Projects/SurfTracker/Data/frames/labeled` (или
   `Data/frames/yt1_unlabeled` для нового батча).
2. Нарисовать первую рамку (клавиша **R** — Create Rectangle), ввести класс `Windsurf`.
   Дальше класс будет подставляться сам (галочка "use last label").
3. Навигация: **D** — следующий кадр, **A** — предыдущий. Сохранение автоматическое
   (JSON рядом с картинкой), либо Ctrl+S.
4. **AI-ассист (по желанию):** внизу в панели Auto-Labeling выбрать
   *MobileSAM (ViT-Huge)* или *Segment Anything 2.1 (Tiny)* — веса уже на диске,
   интернет не нужен. Режим point/box: кликаешь по серфу → получаешь контур,
   он конвертируется в рамку (включить "convert to rectangle"). На CPU MobileSAM
   быстрее, SAM2.1-tiny точнее.
5. Кадры без виндсерфов не пропускай молча — жми **Ctrl+Delete нет**, просто
   сохрани кадр без рамок (пустой JSON тоже полезен: это hard negatives).
6. **Экспорт:** Export → Export YOLO Annotations → указать `classes.txt`
   (файл с одной строкой `Windsurf`). Получишь `labels/*.txt` в YOLO-формате.

### Горячие клавиши
- **R** — новая рамка, **D/A** — след./пред. кадр
- **Del** — удалить выделенную рамку
- **Ctrl+D** — дублировать рамку (удобно: объект почти не сдвинулся между кадрами)
- **Ctrl+колесо** — зум

## Предразметка моделью v1 (сильно ускоряет)

Модель обучена (`models/v1_yolo11s_e99.pt`, подробности — `docs/journal/ОБУЧЕНИЕ_v1.md`):
```bash
cd ~/Projects/SurfTracker
.venv/bin/yolo predict model=models/v1_yolo11s_e99.pt source=Data/frames/yt1_unlabeled/ \
  save_txt save_conf conf=0.30 imgsz=1280
# результат: runs/detect/predict/labels/*.txt
```
Замечены единичные ложные срабатывания на прибрежной траве/ярких пятнах на берегу —
смотри примеры в `docs/journal/v1_viz/`.
Затем в X-AnyLabeling: **Upload → Upload YOLO Annotations**, указать папку labels
и `classes.txt`. Останется только поправить/добавить рамки — это в разы быстрее
разметки с нуля. Порог `conf=0.30` низкий сознательно: лишнюю рамку удалить
быстрее, чем нарисовать пропущенную.

## Запасной вариант: labelme
```bash
~/Projects/SurfTracker/.venv-label/bin/labelme Data/frames/labeled/ --labels Windsurf --nodata --autosave
```
Create Rectangle → рамки, формат JSON. Конвертация в YOLO потом скриптом.

## CVAT (если захочется интерполяции треков)
Плюс CVAT: рамка ставится на ключевых кадрах, между ними интерполируется — для
видео это быстрее покадровой разметки. Минус: тяжёлый, работает в браузере.

**Установлен, но сейчас остановлен** (ел ~3.5 ГБ RAM в фоне без надобности — перешли
на X-AnyLabeling). Данные в volumes целы.
```bash
cd ~/Install/cvat
docker compose up -d      # запуск (порт 8080)
docker compose down       # остановка; данные живут в volumes
```

## Важные нюансы датасета

- **Сплит train/val — только по видео!** Соседние кадры одного видео почти
  одинаковы; если раскидать их случайно, валидация будет враньём.
  `frames_manifest.csv` хранит источник каждого кадра.
- `VID_20230710_150051` — вертикальное видео (1080×1920), это нормально.
- fps у видео разный (30 и 60), поэтому "каждый 30-й кадр" = 1 сек для старых
  и 0.5 сек для новых видео. Если захочется равномерности по времени:
  `.venv/bin/python tools/extract_frames.py --every-sec 1.0`.
- Старый датасет `SurfTracker_v7` пересекается по видео с новыми кадрами —
  при объединении датасетов следи, чтобы кадры одного видео не попали
  и в train, и в val.
- Мелкие объекты: в старом датасете 5% рамок мельче ~24 px (при инференсе 640).
  Если такие важны — при обучении ставь `imgsz=960` или выше.

## Обучение (v1 уже сделано, для справки)
```bash
.venv/bin/yolo detect train model=yolo11s.pt data=Datasets/dataset_v1/surf_gen.yaml \
  imgsz=1280 batch=-1 epochs=150 patience=30 single_cls=True \
  degrees=3 flipud=0 hsv_h=0.005 close_mosaic=20
```
Рабочий скрипт с этим рецептом (площадко-независимый, с resume) — `Datasets/dataset_v1/train.py`.
Подробности и цифры — `docs/journal/ОБУЧЕНИЕ_v1.md`. На CPU не считать — часы вместо минут;
GPU (5070 Ti локально или Colab) обязателен.
