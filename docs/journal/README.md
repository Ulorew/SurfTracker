# Инженерный журнал

Хронологический журнал разработки: замеры, гипотезы, ошибки и их разборы в том
виде, в каком они записывались по ходу работы. Это не руководство — выводы в
ранних записях бывают пересмотрены в поздних, и поправки помечены на месте.

Часть записей (мотор BGM4108, платы Nucleo-F411RE и B-G431B-ESC1, мост
`esp/bt_link`, прошивки `stm/…`) относится к прежней цепи на STM32. Она выведена
из проекта; её код и документы доступны под тегом git `stm-era`.

Актуальные документы: `docs/ПОЛЕ_ЗАПУСК.md` (запуск в поле), `docs/ПРОТОКОЛ.md`
(протокол телефон ↔ плата мотора), `docs/foc_tuning/` (настройка мотора 3506).
